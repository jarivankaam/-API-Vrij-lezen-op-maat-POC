# -API-Vrij-lezen-op-maat-POC
Back-end API voor de PoC 'Vrij lezen op maat'. Levert endpoints voor leesprofielen, leesadvies, catalogus, leeslijsten en docentkoppeling. JWT-authenticatie met rolgebaseerde autorisatie, en gecombineerde dataopslag: relationele DB voor transactionele data en een document store voor de contentcatalogus.
